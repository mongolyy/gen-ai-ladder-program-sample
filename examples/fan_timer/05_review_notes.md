# 人間レビュー用メモ — fan_timer（換気ファン タイマー自動停止制御）

工程⑤（静的チェック）通過後の、人間レビュー観点メモ。
自動チェックでは検出しにくい設計妥当性を中心に確認する。

- 静的チェック: **ERROR 0 / WARN 0**（`04_static_check.txt`）
- 実装方式: 自己保持 + TON タイマー自動停止。状態遷移なし。出力は各1代入で二重コイルなし。

## 生成ロジック（要点）

```st
M_RUNNING    := (RUN_PB OR M_RUNNING) AND NOT STOP_PB AND ESTOP AND NOT T_AUTO_STOP.Q;
T_AUTO_STOP(IN := M_RUNNING, PT := T#30m);
FAN_MOTOR    := M_RUNNING AND ESTOP;
RUN_LAMP     := M_RUNNING;
```

## レビュー観点チェックリスト

### 安全
- [ ] **非常停止のフェイルセーフ**: `ESTOP` は B接点（通常ON、押す/断線でFALSE）。
      ファン出力・運転フラグの両方に `ESTOP` が掛かり、トリップ時に全出力が安全側へ落ちる。
      → 実機配線が本当にB接点か要確認（A接点だと安全方向が逆になる）。
- [ ] **自動再起動の禁止**: 非常停止で `M_RUNNING=FALSE`。解除後もFALSEのままで、
      再度 `RUN_PB` を押すまで再開しない設計。意図通りか確認。
- [ ] **タイマー満了後の再起動**: タイマー満了で自動停止後は `M_RUNNING=FALSE`。
      再度 `RUN_PB` を押すとタイマーがリセットされ、30分計時が再開される。意図通りか確認。

### タイマー動作
- [ ] **PT 値の妥当性**: `PT=T#30m`（30分）はAI仮定値。換気要件に合わせて変更すること。
- [ ] **タイマーリセット動作**: `IN := M_RUNNING` なので M_RUNNING が FALSE になると
      TON タイマーの ET が 0 にリセットされる。意図通りか確認。
- [ ] **スキャン境界の動作**: タイマー満了スキャンで `T_AUTO_STOP.Q=TRUE` → `M_RUNNING=FALSE`。
      次スキャンで `T_AUTO_STOP.IN=FALSE` → `T_AUTO_STOP.Q=FALSE`。1スキャン分の "真の自動停止" 後に
      通常に戻る。この挙動で問題ないか確認。

### 制御ロジック / スキャン依存
- [ ] **セット/リセット優先**: `AND NOT STOP_PB AND ESTOP AND NOT T_AUTO_STOP.Q`。
      停止条件（STOP_PB / ESTOP / タイマー）が AND の否定側にあるため **リセット優先**。
      意図通りか確認。
- [ ] **エッジ検出の要否**: 現状は RUN_PB の「レベル」で判定。押している間ONになるが、
      自己保持があるため離してもONを保持する。チャタリング対策が必要なら
      立上りエッジ検出を追加することを検討。
- [ ] **スキャン順序依存**: `M_RUNNING` を先に確定 → タイマー IN に使用 → 出力に使用。
      同一スキャン内で整合しており、順序依存の不具合なし。

### 割付
- [ ] X/Y アドレス（X0〜X2, Y10/Y11）が実機端子と一致するか（採番案のため要確認）。
- [ ] `M_RUNNING`(M0) に停電保持が必要か。必要ならラッチリレー L へ変更を検討
      （現状は電源OFFでフラグクリア＝再投入時は停止状態から、で妥当と判断）。
- [ ] `T_AUTO_STOP`(T0) の経過時間 ET は停電でリセットされる。
      停電保持が必要な場合は別途カウンタや D レジスタで累積時間を管理することを検討。
