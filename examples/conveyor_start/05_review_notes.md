# 人間レビュー用メモ — conveyor_start（コンベア起動制御）

工程⑤（静的チェック）通過後の、人間レビュー観点メモ。
自動チェックでは検出しにくい設計妥当性を中心に確認する。

- 静的チェック: **ERROR 0 / WARN 0**（`04_static_check.txt`）
- 実装方式: 自己保持（状態遷移なし）。出力は各1代入で二重コイルなし。

## 生成ロジック（要点）

```st
M_RUNNING      := (START_PB OR M_RUNNING) AND NOT STOP_PB AND ESTOP;
CONVEYOR_MOTOR := M_RUNNING AND ESTOP AND NOT WORK_SENS;
RUN_LAMP       := M_RUNNING;
```

## レビュー観点チェックリスト

### 安全
- [ ] **非常停止のフェイルセーフ**: `ESTOP` は B接点（通常ON、押す/断線でFALSE）。
      モータ式・運転フラグ式の両方に `ESTOP` が掛かり、トリップ時に全出力が安全側へ落ちる。
      → 実機配線が本当にB接点か要確認（A接点だと安全方向が逆になる）。
- [ ] **自動再起動の禁止**: 非常停止で `M_RUNNING=FALSE`。解除後もFALSEのままで、
      再度 `START_PB` を押すまで再開しない設計。意図通りか確認。
- [ ] 停止表示の妥当性: ワーク検出による一時停止中も `RUN_LAMP` は点灯維持。
      「停止中はランプ消灯」を望むなら `RUN_LAMP := CONVEYOR_MOTOR;` へ変更を検討。

### 制御ロジック / スキャン依存
- [ ] **セット/リセット優先**: `M_RUNNING := (START_PB OR M_RUNNING) AND NOT STOP_PB AND ESTOP`。
      STOP_PB と ESTOP が AND の否定側にあるため **リセット優先**。
      START と STOP を同時押ししても停止側が勝つ（安全側）。意図通りか確認。
- [ ] **エッジ検出の要否**: 現状は START_PB の「レベル」で判定。押している間ONになるが、
      自己保持があるため離してもONを保持する。チャタリング対策やワンショットが
      必要なら立上りエッジ検出（例: `START_PB AND NOT START_PB_PREV`）の追加を検討。
- [ ] スキャン順序依存: 単一スキャン内で `M_RUNNING` を先に確定→出力に使用しており、
      順序依存の不具合はなし。

### 割付
- [ ] X/Y アドレス（X0〜X3, Y10/Y11）が実機端子と一致するか（採番案のため要確認）。
- [ ] `M_RUNNING`(M0) に停電保持が必要か。必要ならラッチリレー L へ変更を検討
      （現状は電源OFFで運転フラグクリア＝再投入時は停止状態から、で妥当と判断）。
