# 静的チェック規則（工程⑤）とレビュー観点（工程⑥）

`scripts/static_check.py` が実装する検査項目と、人間レビュー（工程⑥）で確認すべき観点。

## 自動静的チェック（scripts/static_check.py）

| ID | 重大度 | 項目 | 内容 |
|----|--------|------|------|
| C001 | ERROR | 二重コイル | 同一出力ラベルへの `:=` 代入が複数（IF/ELSE 同一分岐対は除外） |
| C002 | ERROR | 未定義デバイス | ST 中のラベルがデバイスマスタに存在しない |
| C003 | ERROR | 非常停止欠落 | safety.estop.label が ST 内で参照されていない |
| C004 | ERROR | インターロック未実装 | interlocks の forbid 対象ラベルが ST に出てこない／ロックされていない |
| C005 | WARN | 未使用デバイス | マスタにあるが ST で一度も使われないラベル |
| C006 | WARN | 出力ロジック欠落 | io.outputs のラベルが ST で一度も代入されない |
| C007 | WARN | 構文の対応崩れ | IF/END_IF, CASE/END_CASE の数が不一致 |

- **ERROR が 1 件でも残っていれば工程⑥へ進まない。** 工程②/③/④へ戻して矯正する。
- 重大度・対象は `static_check.py` の実装と一致させること。

### 実行例

```bash
python3 .claude/skills/ladder-gen/scripts/static_check.py \
  --st out/案件A/03_program.st \
  --devices out/案件A/02_device_master.csv \
  --spec out/案件A/01_structured_spec.yaml \
  --report out/案件A/04_static_check.txt
```

終了コード: ERROR が 1 件以上なら非 0、無ければ 0。

## 人間レビュー観点（工程⑥）

自動チェックでは検出しにくい、設計妥当性の確認項目。`05_review_notes.md` に列挙する。

### 安全
- [ ] 非常停止時に**全出力が安全側**へ落ちるか（フェイルセーフ）
- [ ] 非常停止は B 接点（断線=停止）か。A 接点で誤って実装していないか
- [ ] 復帰（リセット）操作なしに自動再起動しないか

### 制御ロジック
- [ ] 自己保持回路のセット/リセット優先が意図通りか
- [ ] スキャン依存（同一スキャン内の代入順序で結果が変わる）箇所がないか
- [ ] エッジ検出（立上り/立下り）が必要な箇所で正しく使えているか
- [ ] タイマ/カウンタのプリセット値・単位が仕様通りか

### 状態遷移
- [ ] 到達不能な状態・抜け出せない状態がないか
- [ ] 異常時に安全な状態へ遷移するか

### 割付
- [ ] X/Y が実機端子と一致するか
- [ ] 停電保持が必要な値が保持領域にあるか

### AI が置いた前提（assumptions）
- [ ] 構造化仕様の `assumptions` を 1 件ずつ確認し、妥当性を判断したか
